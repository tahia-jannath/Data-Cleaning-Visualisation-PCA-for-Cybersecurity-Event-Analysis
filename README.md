# Data-Cleaning-Visualisation-PCA-for-Cybersecurity-Event-Analysis

## Project Description

This project applies **R-based data analysis and Principal Component Analysis (PCA)** to a synthetic cybersecurity dataset generated from Security Information and Event Management (SIEM) data.

The project simulates a healthcare organisation, **FauxCura Health**, investigating historical network security events to identify potential patterns associated with malicious activity. The dataset contains aggregated security event information collected from multiple SIEM sources, including alert categories, network event types, network interactions, data transfer volumes, system activity, response times, security risk levels and event classifications. 

## Purpose

The purpose of the project is to prepare cybersecurity event data for machine learning and identify the features and dimensions that may help distinguish **Normal** and **Malicious** network events.

The analysis focuses on:

* Exploratory Data Analysis (EDA)
* Data quality assessment
* Identification of invalid values and outliers
* Data cleaning
* Statistical summarisation
* Principal Component Analysis
* PCA visualisation
* Identification of important features
* Evaluation of dimensions that may assist in distinguishing malicious events

These objectives are explicitly defined in the assignment brief. 

## Dataset

The source dataset is:

```text
HealthCareData_2024.csv
```

The assignment requires a student-specific sample to be generated by separating **Normal** and **Malicious** events and randomly selecting 400 observations from each class, producing an **800-observation working dataset**. 

The dataset contains categorical, binary and continuous/numeric features, including:

* Alert Category
* NetworkEventType
* NetworkInteractionType
* DataTransferVolume
* TransactionsPerSession
* NetworkAccessFrequency
* UserActivityLevel
* SystemAccessRate
* SessionIntegrityCheck
* ResourceUtilizationFlag
* SecurityRiskLevel
* ResponseTime
* Classification 

## Project Scope

### 1. Exploratory Data Analysis

Categorical and binary variables are analysed by calculating the number and percentage of observations belonging to each category.

Numeric variables are summarised using measures including:

* Missing values
* Minimum
* Maximum
* Mean
* Median
* Skewness

The analysis is performed on the original 800-observation sample before cleaning. 

### 2. Data Cleaning

The dataset is examined for:

* Invalid categorical values
* Invalid numeric values
* Missing data
* Potential outliers

Identified invalid or outlier observations are masked using `NA` values before PCA. 

The cleaned dataset is exported as:

```text
mydata.csv
```

### 3. Principal Component Analysis

PCA is performed on the cleaned numeric features using R's `prcomp()` function.

The analysis investigates:

* Whether standardisation/scaling is appropriate.
* Individual variance explained by the first three PCs.
* Cumulative variance explained.
* Number of PCs required to explain at least 50% of variability.
* PC1, PC2 and PC3 loadings.
* Features contributing most strongly to each principal component. 

### 4. PCA Visualisation

A **PC1 vs PC2 biplot** is created to visualise the dataset in reduced dimensions.

The observations are colour-coded according to their `Classification`, allowing the analysis to investigate whether the PCA dimensions provide separation between:

```text
Normal
Malicious
```

The project evaluates both the observation scores and feature loadings to determine which features may contribute to distinguishing the two classes.

## Testing and Validation

The analysis is validated through reproducible R code.

The assignment requires the data types of the features to be checked using `str()` and any incorrect data types to be addressed. 

The final results must also be reproducible from the submitted R code. The assessment specifically states that results cannot receive marks if they cannot be confirmed by the code. 

## Outcome

The project produces:

* A cleaned 800-observation cybersecurity dataset.
* Exploratory statistics for categorical and numeric variables.
* Identification of data quality issues and outliers.
* A PCA model based on the cleaned numeric features.
* Variance and cumulative variance analysis.
* PC1, PC2 and PC3 loadings.
* A PC1 vs PC2 biplot.
* Interpretation of the relationship between cybersecurity features and event classification.
* Selection of the PCA dimension considered most useful for identifying malicious events.

## Conclusion

This project demonstrates the application of **data cleaning, exploratory analysis and dimensionality reduction to cybersecurity event data**.

By applying PCA to SIEM-derived security events, the project investigates whether combinations of network and system activity features can reveal patterns associated with malicious events. The analysis provides an initial foundation for identifying useful features and dimensions for future machine learning models.

The project also demonstrates the importance of data quality before applying machine learning techniques, particularly when working with aggregated security data containing potential inconsistencies, invalid values, false positives and false negatives.
